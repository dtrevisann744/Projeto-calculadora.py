🧮 Calculadora em Python
Uma simples calculadora de terminal feita em Python, que realiza operações básicas: soma, subtração, multiplicação e divisão.

🚀 Funcionalidades

➕ Somar dois números
➖ Subtrair dois números
✖️ Multiplicar dois números
➗ Dividir dois números
❌ Sair do programa

⚙️ Como funciona
O programa mostra um menu e lê a opção escolhida pelo usuário.
Com base na escolha, ele pede dois números, realiza o cálculo e mostra o resultado.

💡 Exemplo
1 - Somar dois números
2 - Subtrair dois números
3 - Multiplicar dois números
4 - Dividir dois números
5 - Sair

Escolha uma opção: 1
Entre com o primeiro número: 10
Entre com o segundo número: 5
10.0 + 5.0 = 15.0
